# ADR-0005: M2 extension build, IPC and naming

Status: proposed
Date: 2026-10-15
Amends: SPEC.md §2, §4.6, §4.7; ADR-0001

## Context

M2 is the first milestone with code that only runs on macOS: the Endpoint Security
extension, its XPC service, and the container app. These decisions came up while building
it and are not obvious from the code.

## Decisions

1. **Short crate names.** Crates are `pl-core`, `pl-raw`, `pl-xpc`, `pl-es`, `pl-ffi`, and
   the CLI is `plctl`. Owner's direction: "porchlight" is too long to type in code. Bundle
   identifiers (`dev.susanb.porchlight*`), the repository, and the product name are external
   identities and keep the long name.
2. **`pl-xpc` is its own crate.** Both the extension (listener) and the app's core (client)
   need the libxpc shim. A shared crate avoids two copies of the block-taking C.
3. **Owned connections.** The shim hands Rust a retained connection; Rust's `Connection`
   releases it on drop. Sending on a connection the peer has invalidated is then harmless,
   instead of a use-after-free race between the invalidation callback and a send.
4. **Mach service name is Team-ID prefixed:** `2VB7966G7R.dev.susanb.porchlight.extension.xpc`,
   declared as `$(TeamIdentifierPrefix)…` in the extension's `NSEndpointSecurityMachServiceName`.
   System extensions publish mach services under the team prefix. Verify on first install.
5. **`status` is answered with `status_changed`.** One message shape for both "you asked"
   and "it changed", instead of a reply dictionary. The app keeps no pending-reply state.
6. **XcodeGen generates the Xcode project.** `apple/project.yml` is the reviewed source; the
   `.xcodeproj` is generated by `scripts/build-apple` and not committed. A hand-edited
   `project.pbxproj` is unreviewable and could not be validated from Linux. XcodeGen is a
   build-time tool on the developer's Mac (MIT), not a dependency of any shipped artifact.
7. **Placeholder executable.** The extension target compiles `placeholder.c`; a post-build
   phase with declared inputs and outputs copies the cargo-built `pl-es` over it before
   Xcode's CodeSign step. Cargo never runs inside Xcode (ADR-0001 decision 5).
8. **The app is not sandboxed in M2.** The store lives at
   `~/Library/Application Support/dev.susanb.porchlight/events.db`, directory mode 0700.
   Sandboxing interacts with the privileged XPC connection and with M7 self-protection
   paths; it is revisited in M7 with an ADR.
9. **Ring capacity 8,192 for M2.** About 178 MB of virtual memory. The final number is the
   M3 ADR SPEC §12 asks for, measured under the storm test.
10. **Swift 5 language mode.** The app is about 300 lines of UI glue. Strict Swift 6
    concurrency checking can follow once it is built and running.

## Consequences

- `scripts/build-apple` is the one way to build the app. It needs Xcode 26, XcodeGen and the
  pinned Rust toolchain on an Apple Silicon Mac.
- Decisions 4 and 6 are the most likely to need a first-build fix: the exact mach-service
  naming rule and XcodeGen's handling of the `system-extension` product type.
